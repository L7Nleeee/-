AnLedger V1.7

這一版回到最核心的功能：
Apple Pencil 手寫 → 自動保存 → 裝置端 OCR 辨識 → 找到明確金額 → 自動建立記帳。

不需要 OpenAI API Key，也不會呼叫 api.openai.com。

第一次分析會從網路載入 Tesseract.js 的中文＋英文辨識模型，因此第一次可能較慢；模型載入後會留在瀏覽器快取。

測試方式：直接寫「花30元」，停筆約 1 秒，右側應出現辨識結果，若辨識到明確的 30 元，會自動加入總帳。

如果辨識不確定，會先顯示「確認」按鈕，不會直接入帳。


V1.7 重點：先從手寫頁面找深色筆畫與數字區域，再用多個局部視窗辨識 30、100、1000 等金額；明確單一金額會自動入帳，不需要 API Key。


V1.7 交易語意辨識：先判斷是不是支出／收入／投資，再把金額建立成記帳；純日期、電話、數量等裸數字不會直接自動入帳。
