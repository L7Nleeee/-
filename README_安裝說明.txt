AnLedger V1.3

這版重點：Apple Pencil 多頁手寫、掌觸隔離、AI 即時/手動分析、交易自動入帳、低信心待確認、消費/收入/投資三種交易。

AI 使用：在 App 點右上「AI 設定」，貼上 OpenAI API Key，按「儲存並測試」。可選擇是否保存 Key；不保存則只在本次瀏覽工作階段使用。

模型預設：gpt-5.6-luna。

流程：寫一段→自動分析（約停筆 1.8 秒）→高信心交易自動入帳→低信心交易放待確認。按「執行分析」會重新分析今天全部頁面。

注意：V1.3 是個人測試版，API Key 直接由瀏覽器呼叫 OpenAI。若未設定 API Key，手寫與帳務介面仍可使用，但 AI 辨識不會執行。
